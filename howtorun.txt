Double-click start.cmd to start the app and open the browser.
Keep the launcher window open. Press Ctrl+C to stop the server.

Alternatively, run these commands in PowerShell:

Open PowerShell in the bike_rental_dashboard project folder, then run:
.\start.cmd

App address: http://127.0.0.1:8501
If an old tab is blank after restarting the server, press Ctrl+Shift+R.
